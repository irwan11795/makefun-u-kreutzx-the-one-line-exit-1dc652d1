## The entry

> I hereby resign — I spent two years guarding this building at night, and the only thing anyone ever stole was my weekends.

A night-shift security guard's resignation: two years of watching over a building that was never robbed, only to realise the real theft was his own weekends. One line, one breath, one punchline.

## Run

```sh
python3 main.py
```

This writes `entry.txt` (UTF-8, no trailing newline) to `$MAKEFUN_OUTPUT_DIR`, falling back to `/output`, then `output/` in this repo, then a temp directory. The entry is validated before writing: 1–140 characters, exactly one line, not whitespace only.
